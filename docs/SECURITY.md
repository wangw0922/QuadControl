# Security

M0 Apple diagnostics use a user-visible, one-time 256-bit token generated by
the interactive Mac listener. It is never accepted from argv, environment,
file, URL, Bonjour, telemetry, logs, UserDefaults, Keychain, or clipboard.
The terminal shows it once; iOS uses a SecureField and clears it on background,
success, failure, timeout, and explicit disconnect. Terminal scrollback and
screenshots remain shoulder-surfing risks, and `Data` cannot guarantee physical
memory zeroing.

The listener binds loopback by default. LAN requires explicit `--lan
--interface wifi|wired`, the required Network.framework interface, and a
private/link-local peer check. The client separately rejects hostnames and
numeric public targets, allowing only loopback/private/link-local literals;
public peers, VPN, NAT, Bonjour discovery, and relays are out of scope. Pending handshakes are bounded
to 8 and active sessions to 1; token/challenge use is in-memory and atomically
consumed on first successful authentication. Diagnostics are non-sensitive and
are not a production session encryption/control protocol. Never implement
hidden control, credential capture, security-page bypass, or lock-screen bypass.
